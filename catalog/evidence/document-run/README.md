# 自動Run接続の証拠

`live-verification.json` は実Copilot→アプリ→PAD→完了判定の2ケースを、保存ファイルから独立に照合した要約です。原本ログ・実画面は同ファイルに記載したローカル `.work` 内に保持しています。個人の絶対パスを公開用記録へ移していません。

`json-conversion-rejected.robin` は失敗例です。PDFテーブル情報のリストをカスタムオブジェクト用JSON変換へ直接渡したところ、PADが設計時の型エラーを表示しました。成功例の索引・実行許可には含めていません。試験用の当該アクションと依存する書出しは無効化しています。

表の保存には採取・再貼付け・実行確認した `File.WriteToCSVFile.WriteCSV` を使用しました。
