3. 貼り付け用Robin

対象サブフロー: Main
置換範囲: Main 内の全アクション

BLOCK
ON BLOCK ERROR FileNotFound IsUserDefinedErrorCode: True
    SET ErrorHandled TO $'''true'''
ON BLOCK ERROR
    SET ErrorHandledDefault TO $'''true'''
END
    File.ReadTextFromFile.ReadText File: $'''C:\\Users\\yuuki\\ai-prompts\\catalog\\fixtures\\text\\t08-missing-20260910.txt''' Encoding: File.TextFileEncoding.UTF8 Content=> FileContents
    ON ERROR FileNotFoundError
        SET NewVar TO $'''named'''
    END
END
ERROR => LastError Reset: True


このRobinは確認済み原文の組合せです。ERROR => LastError Reset: True は「最後のエラーを取得」で、保存先を LastError、エラー消去をオンにした採取済み設定です。
