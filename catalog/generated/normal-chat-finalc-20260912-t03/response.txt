2. PADで先に確認する設定

新しいフローのMainサブフローへ、次のRobin全体を貼り付けます。入力変数やUI要素、アプリインスタンスを事前作成する必要はありません。

生成される変数と型は次のとおりです。

Files: ファイルのリスト
CurrentFile: 現在処理中のファイルオブジェクト
FileContents: 最後に読み取った.txtファイルのテキスト
TxtSeen: 最後に対象経路へ入ったファイルオブジェクト
OtherSeen: 最後に対象外経路へ入ったファイルオブジェクト
TxtCount: 数値
OtherCount: 数値

フォルダー取得の設定は、フィルター*、サブフォルダーなし、アクセス拒否時は失敗、並べ替えなしです。.txtだけを取得する*.txtフィルターではなく、全ファイルを取得してからIf／Elseで振り分けます。

3. 貼り付け用Robin

対象サブフロー: Main
置換範囲: 空のMain全体、または今回追加する連続した処理範囲全体

Folder.GetFiles Folder: $'''C:\\Users\\yuuki\\ai-prompts\\catalog\\fixtures\\files''' FileFilter: $'''*''' IncludeSubfolders: False FailOnAccessDenied: True SortBy1: Folder.SortBy.NoSort SortDescending1: False SortBy2: Folder.SortBy.NoSort SortDescending2: False SortBy3: Folder.SortBy.NoSort SortDescending3: False Files=> Files
SET TxtCount TO 0
SET OtherCount TO 0
LOOP FOREACH CurrentFile IN Files
IF CurrentFile.Extension = $'''.txt''' THEN
File.ReadTextFromFile.ReadText File: CurrentFile Encoding: File.TextFileEncoding.UTF8 Content=> FileContents
SET TxtSeen TO CurrentFile
Variables.IncreaseVariable Value: TxtCount IncrementValue: 1
ELSE
SET OtherSeen TO CurrentFile
Variables.IncreaseVariable Value: OtherCount IncrementValue: 1
END
END

このRobinはPADからコピーされた実測原文の構成です。.Extensionによる条件分岐を含む13行版について、別フローへの貼付け、保存、再コピー、2回の実行および期待値照合が記録されています。

4. デザイナー上での確認

貼り付け直後に次を確認してください。

For eachの反復値がCurrentFile、反復対象がFilesになっている。
Ifの左辺がCurrentFile.Extension、比較値が.txtになっている。
UTF-8読取りがIfの対象側だけにある。
Else側には読取りアクションがない。
If用とFor each用の2つの終了位置が正しく対応している。
TxtCountとOtherCountが数値変数として認識されている。
変数の加算で、変数名が文字列ではなく変数参照になっている。

特に加算アクションがValue: TxtCountおよびValue: OtherCountになっていることを確認してください。これを文字列リテラルとして設定すると、変数である必要があるというデザイナーエラーになります。
