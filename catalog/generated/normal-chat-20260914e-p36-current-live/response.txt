以下は、欠損する合成ファイルの読取りエラーを、実測済みのアクション単位エラーコード FileNotFoundError で処理するフロー案です。PAD 2.71.115.26224、日本語UI、Power Fx OFFで採取され、元フローと別フローで各2回の実行および期待値照合が行われた原文を使用します。

1. 前提・対象範囲
対象サブフロー: Main
置換範囲: Main の全アクション
入力: 存在しない合成ファイル C:\Users\yuuki\ai-prompts\catalog\fixtures\text\t08-missing-20260910.txt
読取り方式: UTF-8
出力変数: FileContents。読取りが失敗するため、正常な読取り結果は生成されません
エラー処理結果: テキスト変数 NewVar に named
最終エラー: LastError に「ファイルが見つかりません」に対応するエラー情報を取得し、その後エラー情報を消去
保存先・上書き: なし
後続書込み・完了マーカー: なし
2. エラールールの前提と設定

ファイル読取りアクション自身の「エラー発生時」で、「ファイルが見つかりません」を選びます。実測Robinでの組込みエラーコード名は FileNotFoundError です。これは利用者が自由に付けるエラー名ではありません。

ブロック側の ON BLOCK ERROR FileNotFound IsUserDefinedErrorCode: True は、利用者定義コード FileNotFound に対するルールです。組込みコード FileNotFoundError とは別であるため、今回の欠損ファイルエラーには一致しません。また、アクション単位のルールが一致してフローを続行するため、ブロックの引数なしの既定ルールも発火しません。実測では NewVar=named のみが設定され、ErrorHandled と ErrorHandledDefault は設定されませんでした。

「最後のエラーを取得」は、保存先を LastError、エラー消去をオンにします。実測原文は ERROR => LastError Reset: True です。

3. 貼り付け用Robin
BLOCK
ON BLOCK ERROR FileNotFound IsUserDefinedErrorCode: True
    SET ErrorHandled TO $'''true'''
ON BLOCK ERROR
    SET ErrorHandledDefault TO $'''true'''
END
    File.ReadTextFromFile.ReadText File: $'''C:\\Users\\yuuki\\ai-prompts\\catalog\\fixtures\\text\\t08-missing-20260910.txt''' Encoding: File.TextFileEncoding.UTF8 Content=> FileContents
    ON ERROR FileNotFoundError
        SET NewVar TO $'''named'''
    END
END
ERROR => LastError Reset: True

4. デザイナー上の確認

貼り付け後、次を確認してください。

アクション数が 12
BLOCK に対応する最後の END がある
ファイル読取りの直下に ON ERROR FileNotFoundError がある
NewVar の値が文字列 named
LastError が「最後のエラーを取得」の生成変数
デザイナーに入力エラーがない
ファイルパスの各区切りがRobin上で二重バックスラッシュのまま
書込み、送信、削除、完了マーカーが含まれていない
5. 実行と期待結果

フローを保存して実行し、変数ペインで次を照合します。

NewVar は named
LastError は対象パスのファイルが見つからないことを示すエラー情報
ErrorHandled は未設定
ErrorHandledDefault は未設定
フローはファイル読取りで停止せず、「最後のエラーを取得」まで進む
ファイルやその他の成果物は作成されない

同じ欠損パスのまま再実行し、同じ結果になることを確認してください。根拠原文は PAD-Robin-Knowledge-Bundle 内の catalog/evidence/p3-named-error-probe-20260912.robin、実行証拠は catalog/evidence/p3-named-error-acceptance-20260912.json です。
