# Copilotエージェント受入試験 T01〜T10（実行待ち）

このフォルダーは、最終版の指示文と7つの .txt ナレッジを登録した新しい非公開Copilotエージェントで行う受入試験の依頼文・期待値を固定する場所です。ここにある期待値は、生成回答に合わせて後から変更してはいけません。

## 実行前提

- 対象: `copilot/agent-instructions.txt` と `copilot/knowledge/*.txt` を登録した新しい非公開テスト用エージェント。
- 入力: 各ケースで指定する合成データ、専用フォルダー、専用PADフロー。
- 手順: 新しい会話へ依頼 → 回答原文と生成コードを保存 → 手直しせずPADへ貼付け → 設定 → 保存・実行 → 成果物と期待値を照合。
- 失敗時: 元回答を上書きせず、原因分類と失敗位置を保存。指示・ナレッジを変更したら新しい会話で再試験。
- 現在の状態: `NOT_RUN`。`https://microsoft365.com/chat` のM365 Copilot画面にはAgent Builderのエージェント入口が表示されず、PAD側の新規日時取得1設定だけを別証拠で実測済み。
