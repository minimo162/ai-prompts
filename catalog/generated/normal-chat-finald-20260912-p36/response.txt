エラールールの違い
ON ERROR FileNotFoundError は、「ファイルからテキストを読み取る」アクション自身が持つ組込みエラーコードに対するアクション単位ルールです。
ON BLOCK ERROR FileNotFound IsUserDefinedErrorCode: True の FileNotFound は利用者定義のエラー名です。欠損ファイルから発生する組込みの FileNotFoundError とは別物であり、今回のエラーには一致しません。
引数なしの ON BLOCK ERROR はブロックの既定ルールですが、今回のエラーは内側のアクション単位ルールで処理されるため発火しません。
実測では NewVar=named と LastError=ファイル…が見つかりません が確認され、ブロック側の ErrorHandled と ErrorHandledDefault は作成されませんでした。利用者定義名による一致としては扱いません。
PADでの貼り付けと確認

対象サブフローは Main、置換範囲はサブフロー内の全アクションです。貼り付け後、次を確認してください。

デザイナーにエラーが表示されていないこと。
読取りアクション内に ON ERROR FileNotFoundError が入り、その内側に NewVar = named があること。
アクション単位ルールが「フロー実行を続行する」の設定になっていること。
ブロック側の利用者定義ルール、ブロック既定ルール、読取りアクション側ルールの入れ子と各 END が崩れていないこと。
実行後、変数ペインで NewVar がテキスト型の named、LastError がエラー情報になっていること。
ErrorHandled と ErrorHandledDefault が変数ペインに作成されていないこと。
再実行前にも対象ファイルが存在しないこと。存在すると意図したエラー経路を検証できません。
