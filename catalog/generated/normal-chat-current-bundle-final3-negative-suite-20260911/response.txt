N1: ELSE / ELSE IF 分岐内での LOOP BREAK と後続処理を含む構文

生成不可理由

Else、Else-if、EXIT LOOP は個別probeで観測されています。
しかし「ELSEまたはELSE IFの内部でEXIT LOOPを実行し、その後に後続処理が存在する組合せ」は未観測です。
索引には「入れ子分岐、分岐内side effect、エラー後の一般的な後続処理は未確認」と明記されています。

必要な実測

PAD左側アクション一覧で使用アクションを確認。
専用空フローを作成。
Loop → If/Else → EXIT LOOP → 後続アクション の最小構成を作成。
PADからRobinコピー。
空フローへ再貼付け。
保存。
実行。
期待値（EXIT後にどこまで実行されるか）を確認。

現時点でしてはいけない受入判定
