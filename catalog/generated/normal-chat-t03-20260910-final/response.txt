4. デザイナー上の確認方法
アクション順
フォルダー内のファイルを取得
For each
ファイルからテキストを読み取る
End
変数
変数	型
Files	ファイル一覧
CurrentFile	現在のファイル
FileContents	テキスト
ブロック対応
LOOP FOREACH に対応する END が1つ存在すること。
File.ReadTextFromFile.ReadText が For each ブロック内にあること。
エラーなし条件
Files が生成される。
CurrentFile が For each 内で認識される。
FileContents が生成される。
デザイナーで赤エラーにならない。
