3. 貼り付け用Robin

対象サブフロー: Main
置換範囲: Mainサブフロー内の全アクション

Folder.GetFiles Folder: $'''C:\\Users\\yuuki\\ai-prompts\\catalog\\fixtures\\files''' FileFilter: $'''*''' IncludeSubfolders: False FailOnAccessDenied: True SortBy1: Folder.SortBy.NoSort SortDescending1: False SortBy2: Folder.SortBy.NoSort SortDescending2: False SortBy3: Folder.SortBy.NoSort SortDescending3: False Files=> Files
LOOP FOREACH CurrentFile IN Files
    IF CurrentFile.Extension = $'''.txt''' THEN
        File.ReadTextFromFile.ReadText File: CurrentFile Encoding: File.TextFileEncoding.UTF8 Content=> FileContents
    ELSE
    END
END


この命令列の構成要素は、フォルダー全ファイル取得、For each、.Extensionの厳密比較、Else、UTF-8読取りを含め、PADから採取された原文に基づきます。最小形は別の空フローへ貼り付け、保存し、2回実行されています。PAD-Robin-Knowledge-Bundle
