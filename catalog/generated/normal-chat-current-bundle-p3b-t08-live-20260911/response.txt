1. 前提・対象範囲・未確認点
目的: 存在しない合成入力ファイルをUTF-8で読み取り、ファイル不存在のエラー状態と最終エラーだけを確認する。
入力: C:\\Users\\yuuki\\ai-prompts\\catalog\\fixtures\\text\\t08-missing-20260910.txt
出力変数:
FileContents: 読取り成功時のテキスト。ただし今回は生成されないことが期待される。
ErrorHandled: 名前付きエラー経路を通った場合のテキスト。
ErrorHandledDefault: 既定のエラー経路を通った場合のテキスト。
LastError: 「最後のエラーを取得」のエラー情報オブジェクト。
保存先・上書き: なし。
成功条件:
書込みや完了マーカーが実行されない。
ErrorHandledDefault が true になる。
LastError に「ファイルが見つかりません」に相当する内容が表示される。
実測環境: PAD 2.71.115.26224、日本語UI、Power Fx OFF、合成データ。
重要な境界: 名前付きカスタムエラー FileNotFound の一致は成功確認されていません。既定の「すべてのエラー」経路は2回成功しています。ブロック部分と「最後のエラーを取得」は別々にPADから採取され、掲載順に組み合わせたもので、単一クリップボード原文としての一致証明ではありません。ただし、この組合せはクリーンな2回の実行で ErrorHandledDefault=true と「ファイルが見つかりません」の LastError が確認されています。

根拠は PAD-Robin-Knowledge-Bundle 内の catalog/evidence/p3-error-handler-measured-20260911.json、catalog/evidence/p3-error-default-handler-20260911.json、catalog/evidence/p3-get-last-error-standalone-20260911-reset.robin です。

3. 貼り付け用Robin

対象サブフローは Main、置換範囲は空のサブフロー全体です。次の組合せには、未確認の名前付き FileNotFound 経路も実測掲載原文どおり含まれます。実際の捕捉は既定エラー経路を成功条件にしてください。

BLOCK
ON BLOCK ERROR FileNotFound IsUserDefinedErrorCode: True
    SET ErrorHandled TO $'''true'''
ON BLOCK ERROR
    SET ErrorHandledDefault TO $'''true'''
END
    File.ReadTextFromFile.ReadText File: $'''C:\\Users\\yuuki\\ai-prompts\\catalog\\fixtures\\text\\t08-missing-20260910.txt''' Encoding: File.TextFileEncoding.UTF8 Content=> FileContents
END
ERROR => LastError Reset: True


この命令列にはファイル書込み、完了マーカー、公開処理はありません。読取りアクションのUTF-8設定と対象パス、既定エラーハンドラー、ERROR => LastError Reset: True は添付ナレッジの実測掲載内容に基づきます。

BLOCK と最後の END の対応にデザイナーエラーがない。
読取りアクションがブロック内に配置されている。
