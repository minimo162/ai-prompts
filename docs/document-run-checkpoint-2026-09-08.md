# Office・PDFの自動Run接続チェックポイント

ユーザーの追加指示に基づき、PAD左欄からのOffice/PDFアクション採取、生成プロンプトへの収録、アプリの検証器・実行・成果物観測・完了判定への接続を行いました。汎用エージェント全体や社内・別PCの受入完了ではありません。

## 実装

- Officeの17種類22設定、PDFの5種類11設定を採取。PDF表を保存するためCSV書出し1設定も追加しました。カタログ全体は34種類51設定です。
- アプリ内に採取したパラメーター形式を組み込み、インスタンスの型・生存期間・閉じ忘れ、対象範囲、新規出力、ページ・セル範囲を検査します。Office/PDF/表CSVは直列のトップレベル操作に限定します。
- 既存文書は検査時ハッシュと一致するジョブ内作業コピーへ移して開きます。実行用コードでは検証済みファイル引数だけを置換し、本文中の同じパス文字列は変更しません。入力原本の変更を検出した場合は完了にしません。
- xlsxの格納値、docxの論理テキスト、pptxのスライド数・順序・テキストを、容量制限と外部参照禁止を持つパッケージ読取りで観測します。
- PDFにはコントローラー管理のテキスト読取りを追加します。読取りファイルは成果物外の専用領域に置き、実行結果のファイルハッシュと結び付けます。画像抽出は生成ファイルと件数・ハッシュのマニフェストを観測します。
- 表は `File.WriteToCSVFile.WriteCSV` でUTF-8・見出し付きCSVへ保存できます。PDF結果のリスト自体をJSON変換へ渡す案はPADの設計時型エラーになったため採用していません。
- 成果物に検査範囲を表示し、検証済みIDと現在ハッシュを照合してOffice/PDF/画像/CSVを開く経路を追加しました。CSVの式として解釈され得る値は、データを改変せず直接オープンを拒否します。
- クリップボードが一時的に開けないHRESULT `800401D0` に限り、読取りだけを最大20回・50ms間隔で待ちます。Copy・Paste・Runは再発行しません。

## 先行失敗と回帰

先行するOffice自動Runは、既存Mainのコピー内容を読み取る段階でクリップボード読取りに失敗しました。`main_status=not_changed`、成果物なし、`restore_failed` として保持しています。成功へ書き換えず、同じジョブを再実行していません。読取り待機を追加した別候補・新しいジョブで上記の成功を確認しました。

初回の全体試験には未更新の配布バインディングとPlaywrightモジュール未指定による失敗がありました。候補を正しく再封印し、実行環境を指定して再検証しました。入力パッケージ検査・読取り待機を含む最終候補の39スイートはすべてPASSで、試験前後の製品3ファイルも同一です。[最終の非ライブ記録](../catalog/evidence/document-run/nonlive-verification.json)に記載しています。非ライブ試験を実機・CI成功とは扱いません。

## 残る範囲・制約

- Officeの既存文書を対象としたアプリ自動Runは未検証です。入力ステージング・型・ハッシュはローカル契約試験で検証しました。
- Office/PDFで前回Runの成果物を再入力にする経路は未接続です。現在Run内で先に生成した文書は再入力に使えます。従来のテキスト成果物の再利用契約は保持しています。
- 表示上の「完了」は、観測可能な文字・値・ページ内容等の依頼についてです。書式、図形位置、グラフ、OCR、署名等を検証したものではありません。
- 数式、外部関係、マクロ、埋込みアクティブオブジェクト、データ接続、Wordフィールド等を持つ入力は拒否します。Excelの検査・範囲は4096セル、Office/PDFの入力総量は64MiB等の制限があります。
- PDF統合の逆順挙動はこの版・2入力の実測です。3入力以上や別PAD版へ一般化していません。PDFテキストのページ境界にも区切りなしの連結があります。
- 長大な成果物、複数業務・復旧全般、別利用者・別PC、社内利用許可は未受入です。#5・#9等はOPENを維持します。
- 通常の利用者キャッシュや社内共有先の更新は今回行っていません。今回の公開対象はソース、採取原文、検証記録です。
