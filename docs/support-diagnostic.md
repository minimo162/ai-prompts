# 問い合わせ用情報の範囲

画面の「問い合わせ用情報（本文なし）」で内容をプレビューしてからJSONを保存します。自動アップロードはありません。診断schema_version 2では次を分けて記録します。

- 現在のアプリ版・ハッシュと、表示しているジョブを開始したアプリのハッシュ。
- OS/Windows PowerShell、接続アダプター版、インストール済みEdgeのファイル版とPADのAppxパッケージ版。PAD画面の製品版とは別で、稼働プロセスとの一致も未確認です。取得できないインストール形態・値はunavailableとします。
- 依頼・要求IDから作る短いハッシュ参照。元ID、入力パス、業務本文、プロンプト、AI全文は出しません。
- 保存された接続記録の段階、固定エラー分類、所要ミリ秒、要求期限、送信予約・クリック応答・完全応答の各状態。クリック応答は業務成功を意味しません。
- Mainの保全状態、クリップボードの保全状態、復旧が必要か、停止が確認されたか。本文を含み得る警告文字列や生の例外メッセージは出しません。

接続記録は最新200ファイルまでの読取りに限定し、その中で表示中ジョブと要求IDが一致する最新記録だけを採用します。該当なし、読取り不能、不正な値はnull/unknownとし、0秒や復旧済みに置き換えません。過去の記録に期限がなければ期限はnullです。新しい診断のためにCopilotやPADへ接続・送信したり、過去の記録を書き換えたりしません。

このJSONはサポートの切り分け用です。匿名化したIDは同じ依頼を関連付けるための参照であり、匿名性の保証や、実M365/PAD・社内PCの受入証明ではありません。内容承認や出荷承認は別途必要です。

回帰入口は`tests/Test-OfflineDiagnostic.ps1`、`tests/Test-ConnectionContract.ps1`、`tests/Test-CsvUi.cjs`。内部の合成秘密文字列・個人パス・壊れた型の除外、別ジョブ混入の拒否、実Edgeでのプレビューと保存一致を検証します。UI試験のAI境界はmockであり、実M365試験とは区別します。
