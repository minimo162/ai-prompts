# 汎用依頼の成果物を確認する

新しい汎用Runでは、PAD成功後に確認した各成果物へサーバーがIDを付けます。このIDは履歴や再読み込みでも変わりません。古い履歴へ読取り時に新しいIDを付けることはしません。

「成果物を開く」はジョブIDと成果物IDだけを送ります。サーバーは表示中の成果物と観測記録の一致、同じジョブのrun/artifacts内であること、ファイルの存在と現在のSHA256を確認してからWindowsへオープンを要求します。別ジョブ・不明ID・変更/削除・範囲外・重複IDは拒否します。直接開く対象は汎用RunではTXT/JSON、CSVワークフローでは既存の検証済みCSV/JSONです。実行形式等は直接開きません。

Windowsの関連付けが未設定・無効な場合は、アプリの選択画面が表示されることがあります。オープン要求の成功は、関連付け先で内容が表示されたことの証明ではありません。

アプリ内の「実行時に確認した内容」は、サーバーが実行時に読んだ内容のプレビューです。省略時は「一部」と表示します。後から保存ファイルを変更しても、この観測記録は更新しません。HTML等の内容を実行せず、テキストとして表示します。
